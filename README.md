# Feature: Core Gameplay Prototype

> **Ветка:** `feature/core-gameplay`
> **Цель:** Реализация первого играбельного прототипа механик Усадьбы и Исследования.

---

## 🎯 Задачи ветки (Sprint Backlog)

### 1. Контроллер персонажа (`Player`)
- [ ] 8-направленное передвижение с нормализацией вектора скорости.
- [ ] Система ресурсов: Здоровье (`HP`) и Выносливость (`Stamina`).
- [ ] Уклонение (Dodge Roll / Dash) с фреймами неуязвимости (`i-frames`) и расходом стамины.
- [ ] Переключение активного инструмента / оружия (Руки, Мотыга, Меч, Лейка).

### 2. Сетка хозяйства (`Farming Grid`)
- [ ] Тайловая сетка земли (`TileMapLayer`).
- [ ] Вспашка земли мотыгой (`SoilState: Tilled`).
- [ ] Полив земли лейкой (`SoilState: Watered`).
- [ ] Посадка семян (напр. Репа, Сон-трава).
- [ ] Рост культур по сигналу нового дня (`EventBus.day_advanced`).
- [ ] Сбор урожая.

### 3. Боевая система (Souls-lite Prototype)
- [ ] Хитбоксы и хертбоксы (`Area2D` со слоями коллизий).
- [ ] Оружие двойного назначения: Мотыга и Серп наносят урон врагам.
- [ ] Простой тестовый враг / манекен с телеграфируемой атакой.
- [ ] Блок щитом / оружием (снижение урона и расход стамины).

### 4. Цикл отдыха и поражения
- [ ] Святилище малого дуба (восстановление здоровья и стамины).
- [ ] Механика гибели: возрождение у дуба, создание сущности «Незаконченная строка» с потерянным пеплом.
- [ ] Подбор строки для возврата ресурсов.

---

## 🧪 Инструкция по тестированию

1. Открыть проект в Godot 4.3+.
2. Запустить `scenes/main/Main.tscn` (или клавишей `F5`).
3. Проверить перемещение, полив грядок и бой с тестовым противником.
