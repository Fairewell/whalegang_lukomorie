# Лукоморье: Пепел Сказаний — Ветка разработки (`dev`)

> **Ветка:** `dev` (Active Development & Integration)

Интеграционная ветка проекта. Сюда вливаются фичи из веток `feature/*` после верификации работоспособности.

---

## 🛠️ Архитектура и структура папок

```
Lukomorye/
├── assets/                  # Спрайты, шрифты, аудио
│   ├── sprites/             # player, environment, crops, enemies, ui
│   └── audio/               # music, sfx
├── resources/               # Пользовательские ресурсы (.tres)
│   ├── items/               # Предметы и инструменты
│   ├── crops/               # Семена и растения
│   └── story_lines/         # Сказочные строки
├── scenes/                  # Сцены игры (.tscn)
│   ├── main/                # Точка входа (Main.tscn)
│   ├── player/              # Персонаж, камера
│   ├── farm/                # Система грядок и усадьбы
│   ├── world/               # Сказочные биомы и локации
│   ├── enemies/             # Противники и боссы
│   └── ui/                  # HUD, инвентарь, Книга, диалоги
├── scripts/                 # Исходный код (GDScript)
│   ├── autoload/            # EventBus, TimeManager, MoralityManager, BookManager
│   ├── player/              # Контроллер, статы
│   ├── farm/                # Логика урожая и полива
│   ├── combat/              # Хитбоксы, урон, навыки
│   ├── dialogue/            # Диалоговые структуры и триггеры
│   └── resources/           # Классы Custom Resource
└── shaders/                 # Шейдеры (пепел, чернила, зеркала)
```

## 📌 Правила для контрибьюторов

1. Вся новая функциональность пишется в отдельных ветках `feature/<название-фичи>`.
2. Перед слиянием в `dev` ветка должна быть протестирована на отсутствие синтаксических ошибок и регрессий.
3. Коммиты оформляются по конвенции Conventional Commits (`feat:`, `fix:`, `refactor:`, `docs:`).
