# Лукоморье: Пепел Сказаний (Lukomorye: Ashes of Tales)

> **Ветка:** `main` (Стабильная версия / Релиз)

Уютная, мрачная 2D RPG о хозяйстве, памяти и мире, который слишком долго повторяет одну и ту же сказку.

---

## 📖 О проекте

* **Движок:** Godot 4.3+ (GL Compatibility / Forward+)
* **Жанр:** Life-Sim / Action-RPG / Souls-lite (вид сверху, 2D пиксель-арт)
* **Разрешение:** Базовый рендер `640 × 360` с целочисленным масштабированием
* **Ключевая формула:** *«Днём игрок выращивает будущее. Ночью он отправляется в сказки, которые не умеют закончиться».*

---

## 🎮 Ключевые особенности

1. **Двойной игровой ритм:**
   * **Днём (Усадьба Сказителя):** Земледелие, уход за сказочными культурами, рыбалка по ряби, обустройство убежища для освобождённых героев.
   * **Ночью (Сказочные земли):** Исследование искажённых сказок, требовательные тактические сражения, поиск Буквенного пепла и Сердцевинных строк.
2. **Великая Книга:**
   * Каждую сказку можно решить четырьмя способами: *Восстановить*, *Переписать*, *Вычеркнуть* или *Оставить незавершённой*.
3. **Триада Морали:**
   * *Милосердие / Воля / Порядок* определяют состояние мира, дуба и диалоги с жителями.
4. **Уникальная рыбалка:**
   * Ловля рыбы по визуальным кругам, ряби и направлению течения вместо аркадных полосок.

## 🕹️ Управление по умолчанию

| Действие | Клавиатура | Геймпад |
| :--- | :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` / Стрелки | Левый стик / D-Pad |
| **Основное действие / Атака** | `ЛКМ` / `J` | `X` / `Square` |
| **Вторичное действие / Блок** | `ПКМ` / `K` | `LT` / `L2` |
| **Уклонение / Рывок** | `Space` | `A` / `Cross` |
| **Взаимодействие** | `E` | `Y` / `Triangle` |
| **Сказочная строка (Навык)** | `Q` | `RB` / `R1` |
